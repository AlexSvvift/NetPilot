# Учебный маршрут по NetPilot

Этот файл помогает изучать проект не целиком сразу, а небольшими шагами.

## Шаг 1. Запусти и посмотри глазами

Открой web-панель, добавь `https://example.com`, запусти ручную проверку и
посмотри, как меняются статус и время ответа.

Главная мысль: NetPilot - это не VPN-клиент и не VPN-сервер. Это наблюдатель,
который проверяет, доступен ли уже существующий сайт, сервер или порт VPN.

## Шаг 2. Пойми путь одной цели

Проследи цель в таком порядке:

1. Форма в `web/index.html`.
2. Отправка JSON в `web/app.js`.
3. `POST /api/targets` в `app/api/routes.py`.
4. Валидация `TargetCreate` в `app/schemas.py`.
5. Запись через `app/repository.py`.
6. Таблица `Target` в `app/models.py`.

## Шаг 3. Пойми проверку

Открой `app/services/monitoring.py`:

- HTTP выполняется через `httpx`;
- TCP использует `asyncio.open_connection`;
- UDP создает datagram endpoint;
- каждая проверка возвращает единый `CheckOutcome`.

Единый результат важен: web-панели не нужно знать детали каждого протокола.

## Шаг 4. Пойми расписание

`app/services/scheduler.py` бесконечно выполняет цикл:

1. получает активные цели;
2. выбирает цели, которым пора проверяться;
3. запускает проверки параллельно;
4. записывает результат;
5. ждет несколько секунд и повторяет цикл.

При остановке приложения FastAPI корректно отменяет фоновой task.

## Шаг 5. Пойми API

Запусти Swagger и попробуй endpoints вручную. Для каждого endpoint ответь себе:

- какой HTTP-метод используется;
- какой JSON приходит;
- что проверяет Pydantic;
- какой код ответа получит клиент;
- где данные сохраняются.

## Шаг 6. Пойми тесты

Запусти `python -m pytest`. Затем прочитай тесты:

- `tests/test_api.py` показывает сценарий пользователя;
- `tests/test_monitoring.py` запускает локальный TCP-сервер и проверяет его.

Хороший следующий шаг - добавить тест на недоступный порт и тест истории.

## Вопросы для самопроверки

1. Чем `POST` отличается от `GET`?
2. Зачем нужны Pydantic-схемы, если есть SQLAlchemy-модели?
3. Почему таймаут обязателен для сетевой проверки?
4. Что произойдет, если цель выключить через `enabled=false`?
5. Почему API-ключ нельзя считать полноценной системой пользователей?
6. Что изменится, если заменить SQLite на PostgreSQL?
7. Почему UDP нельзя проверять точно так же, как TCP?
